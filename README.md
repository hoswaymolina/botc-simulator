# Blood on the Clocktower Simulator

A Python project to simulate the social deduction game Blood on the Clocktower.

## Purpose

The goal of this project is to build a simulation engine that models game mechanics and eventually explore statistical analysis and machine learning applications.

## Current Features

- Player/Role classes
- Role assignment system

## Planned Features

- Game phases
- Night actions
- Voting system
- Full game simulation
- Statistical analysis
- Machine learning experiments

## Technologies

- Python
- Git/GitHub
