# Blood on the Clocktower Simulator

This project is an unofficial simulator inspired by *Blood on the Clocktower*,
created by The Pandemonium Institute. All game concepts, role names, and related
intellectual property belong to their respective owners. This project is for
educational and research purposes and is not affiliated with the official game.

## Purpose

The goal of this project is to build a simulation engine that models game
mechanics and eventually explore statistical analysis and machine learning
applications.

## Current Features

- Player/Role classes
- Role assignment system

## Planned Features

- Game phases
- Night actions
- Voting system
- Full game simulation
- Statistical analysis
- Machine learning experiments

- Python
